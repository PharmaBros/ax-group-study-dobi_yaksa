# 0_수집분석 — 미리 모아 둔 게시물과 분석

앤서니 팀이 도비약사(@dobi_yaksa) 공개 게시물을 모으고 **사실만** 분석한 자료다(게시물 그림, 캡션 통계, 그림 크기·색 실측, 글자 크기·여백 실측, 게시물 종류 판정). 부품 후보·대표 편 목록·디자인 설계 초안처럼 우리가 판단한 문서는 넣지 않았다 — 그 판단은 이 묶음의 클로드가 `1_공통설계서/설계하기.md`대로 새로 한다. 약사님이 게시물을 다시 모으지 않아도 되게 넣었다. **이 폴더의 파일은 원본이므로 고치지 않는다**(잘라 쓸 때는 복사해서 쓴다).

- 모은 날: **2026-11-03**(게시물 목록은 2026-11-02 격자에서, 캡션 전문·슬라이드 그림은 2026-11-03). 그 뒤에 올라온 게시물은 없다.
- 공개 카드뉴스(캐러셀) 슬라이드와 캡션만 있다. 릴스·스토리·개인 게시물·따로 받은 본인 사진은 없다.

## 편 폴더 이름 규칙

`게시물/<게시 날짜>_<아이디>/`
- 게시 날짜 = 한국 날짜(`YYYY-MM-DD`). 아이디 = 인스타 주소 `instagram.com/p/<아이디>/`의 그 글자.
- 안에 `1.jpg, 2.jpg …` = 장 순서 그대로. 번호가 빠진 장은 없다.
- `출처.json` = 주소·게시일·분류·장 수·받은 날·원본 해상도·**`영상 장`**(영상이라 미리보기 그림만 있는 장 번호 — 작고 흐리므로 색·크기를 재거나 견본·블라인드에 쓰지 않는다).
- `글.md`는 `2026-10-25_De6PLeGAbzZ`에만 있다(장별 글을 받아 적은 것).
- 그림 크기는 편마다 다르다(1080×1350, 1320×1760, 3274×4096 등). 4:5와 3:4가 섞여 있다 — 편별 표와 쓰면 안 되는 장은 `3_작업안내/도비약사_작업안내.md` 1·2장.
- 종류는 `분류.md`가 기준이다. `출처.json`의 `분류`와 다른 편이 둘 있다(DdbPGMjgeT0·De6PLeGAbzZ — 분류.md의 '건강 정보'가 맞다).

## 분석 문서 속 옛 경로 읽는 법

분석 문서는 우리 쪽 보관 폴더 이름으로 경로를 적었다. 이 묶음에서는 아래처럼 읽는다.

| 문서에 적힌 경로 | 이 묶음 안 자리 |
|---|---|
| `01/게시물목록.json`·`01_수집_인스타게시물/…`·`01/프로필.md` | `0_수집분석/게시물목록.json`·`프로필.md` |
| `02_대표게시물_슬라이드/슬라이드/<편>/`·`02_대표게시물_슬라이드/정보형_추가/<편>/` | `0_수집분석/게시물/<편>/`(두 곳을 한 폴더로 모음) |
| `02/분류.md` | `0_수집분석/분류.md` |
| `03_분석_계정특징/2026-11-03_1단계_실측.md` 등(`2026-11-03_` 머리) | `0_수집분석/1단계_실측.md`·`캡션통계.md`·`슬라이드실측.md` |
| 계정별메모·정보형 모양표·커스텀 설계서(우리가 쓴 설계 문서) | 묶음에 없음 — 이번에 약사님 쪽에서 새로 만든다(`7_결과/설계/`·`2_커스텀설계서/`) |
| `설계서/공통/작업_설계서.md`·`도구/…`(수집검증·캡션통계 도구 등)·`git-docs/…` | 묶음에 없음(우리 쪽 작업 문서·도구) — 필요 없다 |
| `한눈에보기/`, `_수정전`·`_이전` 같은 옛 판, 검수 기록(`04_설계서검토/…_검수_…`), `05_동의와설정/…`, `수집검증` | 묶음에 없음(넣지 않음) |
| 우리가 만든 디자인 시스템 화면·부품 견본·그림 조각 | 묶음에 없음 — 이번에 약사님 쪽에서 새로 만든다 |

- 문서에 나오는 `계정A`~`계정G`(도비 = 이 계정 자신이라 이름 그대로)는 다른 약사님 계정 이름을 가린 것이다. "앤서니"는 그룹스터디 진행자다(막히면 연락할 사람).
- 분석 문서의 숫자(편 수·장 수)는 그 문서를 쓴 때 기준이라 서로 조금 다를 수 있다(예: 슬라이드실측은 31편, 슬라이드 받은 것은 45편).
